# Support

## Before reporting a problem

Check the [installation guide](docs/INSTALLATION.md), the relevant entry in the [tool guide](docs/TOOLS.md), and [existing issues](https://github.com/AlexRacing98/LocalConvert/issues). Include your app version and whether you are using Android or Windows.

## Report a bug

Use the [bug report form](https://github.com/AlexRacing98/LocalConvert/issues/new?template=bug_report.yml). Describe what you selected, what happened, and what you expected instead. A small sample file with invented content is more useful than a screenshot containing personal information.

GitHub issues are public. Remove passwords, personal documents, QR contents, location metadata, account details, and private file paths from anything you post.

## Contact privately

Email **[zhivkovalexander98@gmail.com](mailto:zhivkovalexander98@gmail.com)**, or choose **Settings → Report a bug** inside LocalConvert. That opens a draft in your default mail app; you choose when to send it.

For a suspected security or privacy problem, use email rather than posting sensitive details in a public issue. No response-time guarantee is offered.

## Suggest a feature

Use the [feature request form](https://github.com/AlexRacing98/LocalConvert/issues/new?template=feature_request.yml). Explain the task you want to complete, the input/output formats involved, and how it should work offline. A request does not mean a feature has been promised or scheduled.
