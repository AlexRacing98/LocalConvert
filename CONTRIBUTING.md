# Contributing ideas and reports

Thank you for helping improve LocalConvert.

This is the official downloads, documentation, and issue-tracking repository. Application source is not published here, so this repository does not provide a source build or accept application-code patches against the release binaries.

You can contribute by:

- Reporting a reproducible problem through the [bug form](https://github.com/AlexRacing98/LocalConvert/issues/new?template=bug_report.yml).
- Proposing an offline workflow through the [feature form](https://github.com/AlexRacing98/LocalConvert/issues/new?template=feature_request.yml).
- Suggesting clearer documentation or submitting a focused documentation correction.
- Testing a release on your device and describing the platform, version, inputs, and result.

Search existing issues before opening a new one. Keep each report focused on one problem. Use invented sample content and remove personal information before sharing files or screenshots.

Please do not submit generated executables, signing keys, credentials, personal documents, or private application source. For private reports, use the contact details in [SUPPORT.md](SUPPORT.md).
