LocalConvert 的开发者和提供者为 VIOLETA JIVKOVA，即华为应用市场分发账户的已认证个人主体。开发者展示名称为 AlexRacing98。本隐私政策适用于 LocalConvert 安卓应用，包括通过华为应用市场分发的版本（包名：app.localconvert），并说明公开隐私政策网站的托管方式。如有隐私问题，请联系 zhivkovalexander98@gmail.com。

2. 文件在您的设备上处理

LocalConvert 在您的设备上转换和处理文件，无需注册 LocalConvert 账号。应用不会将您的文件、文本、图像、二维码内容或生成的密码上传给我们或转换服务。安卓应用不申请互联网访问权限，也不依赖 Google Play 服务。

应用不使用广告、跟踪、统计分析或自动崩溃报告服务。我们不收集设备标识符、通讯录或您的位置，也不出售或出租您的个人信息。

3. 在本机使用的信息

应用仅使用您所选择的工具和设置所需的信息：
  • 文件和文本：您选择的图像、文档、文件夹和文本在本机处理，用于完成转换、编辑、文件整理、扫描及您要求的其他操作。部分操作会在应用缓存中生成临时文件。Android 保存页面状态时，文本草稿可能保存在应用私有存储空间中，以便恢复未完成的内容。
  • 可选姓名和偏好：您为欢迎语填写的姓名和主题偏好保存在本机。填写姓名并非必需，也不会发送给我们。
  • 工具推荐：应用在本机保存最近打开的 128 个工具编号，用于推荐工具。该记录不包含文件内容、密码或二维码内容。
  • 最近文件：历史记录最多保存 50 条结果记录，包括文件名、位置引用、文件类型、大小、使用的工具和创建时间，以便您再次打开或分享结果。
  • 隐私提示：您明确同意的政策版本保存在本机，以避免重复显示相同提示。选择“同意”表示同意本政策描述的信息处理；选择“拒绝”将在使用工具前关闭应用。仅打开政策不会记录同意。同意记录不会发送给我们，也不会授予相机或文件访问权限。
  • 货币工具：计算使用应用内置、手动输入或导入的汇率。应用不会在后台获取汇率。

4. 权限、相机和剪贴板

相机：仅在您选择使用相机扫描二维码时，LocalConvert 才申请相机权限。相机画面在本机处理，扫描器不会保存或传输这些画面。您可以拒绝该权限，或在 Android 设置中撤销权限；其他工具仍可使用。

文件和文件夹：您通过 Android 文件选择器选择应用可以访问的文件或文件夹。文件夹工具检查您选择的文件夹，以完成您要求的操作。应用可能保留对已选择的保存结果的访问权限，以便从历史记录中再次打开。

剪贴板：仅在您选择“粘贴”或“复制”操作时，应用才读取或写入系统剪贴板。操作系统或剪贴板服务也可能根据其设置处理剪贴板内容。

图像文件本身可能包含位置标签等元数据。LocalConvert 不申请设备定位权限。您可使用“Remove metadata”（移除元数据）生成不复制个人元数据的图像副本；图像中可见的信息不会因此被移除。

5. 分享、外部应用和问题反馈

只有在您主动分享文件、使用其他应用打开结果或保存到云端存储位置等情况下，文件才会交由 LocalConvert 以外的服务处理。这些应用和存储服务可能根据其自身政策和设置上传或同步文件。

Report a bug（报告问题）会在您的邮件应用中打开一封可编辑的草稿，收件人为 zhivkovalexander98@gmail.com。草稿包含应用版本和问题描述提示。在您点击发送前，不会发送任何邮件。如果您联系我们，我们会收到您的邮箱地址以及您主动发送的邮件内容或附件。这些信息仅用于回复、调查问题和处理您的请求。邮件服务商会为投递和保存邮件而处理相关信息。

除非处理您的请求确有必要，请勿发送私人文档、密码或其他敏感内容。在公开 GitHub issue 中发布的内容可被其他人看到。

打开汇率来源、GitHub 等外部链接会使用您的浏览器，并适用目标网站的隐私规则。华为应用市场依据其自身隐私政策独立处理下载和商店相关信息。

内置程序库：PDFBox、ZXing、AndroidX ExifInterface、TIFF/AVIF/JPEG XL 解码器、Kotlin 和加密算法程序库用于本机文档、图像及二维码处理。它们不是广告或统计分析 SDK，我们不使用它们向其作者发送个人信息。

6. 保存期限和您的选择

文件会保留在您选择的位置，直到您删除或移动。移除历史记录只会移除引用，不会删除已保存的文件。旧记录可能超出 50 条的历史记录上限而被移除，但文件仍会保留。
  • 在 Settings（设置）→ 隐私 → 撤回同意中可撤回同意并关闭应用。文件和设置将保留，下次打开应用时会再次显示隐私提示。撤回同意不会撤销您此前要求的操作。
  • 在 Settings（设置）中修改或清空可选姓名。
  • 在设置中选择 Reset recommendations（重置推荐），清除本机推荐记录。
  • 在 History（历史记录）中移除单条记录。
  • 通过 Android 设置清除 LocalConvert 缓存或应用数据、撤销相机权限或卸载应用。清除应用数据会删除本机设置、历史记录、文本草稿、推荐记录和隐私政策同意记录；已导出到应用之外的文件仍会保留，需另行删除。

应用已禁用 Android 对其私有应用数据的自动备份。您导出的文件仍可能由您使用的目标存储服务或设备服务进行备份。

我们无法远程访问或删除仅存储在您设备上的文件。对于您主动通过邮件发送的信息，您可以通过下方联系方式请求访问、更正或删除。反馈邮件仅在处理请求及履行适用法律义务所需期间保留。根据您所在地区，您还可能享有请求限制或反对处理、获取可转移副本，或向当地个人信息保护主管部门投诉的权利。

7. 安全和儿童

本机处理减少了传输文件的需要。您的设备安全状况，以及您选择的其他应用或存储位置，也会影响文件安全。任何存储或传输方式都无法保证绝对安全。Base64 编码和文件校验值不属于文件加密。

应用不要求提供年龄信息，也不会明知而通过应用收集儿童的个人信息。如果您认为儿童通过问题反馈向我们发送了个人信息，请联系我们处理。

本页面托管于 GitHub Pages。我们没有在页面中添加广告、统计分析脚本、跟踪像素或第三方字体。GitHub 说明，访问 GitHub Pages 网站时会出于安全目的记录访问者的 IP 地址。网站托管与 LocalConvert 的离线文件处理相互独立。请参阅 GitHub Pages 文档和 GitHub 隐私声明。

9. 政策更新和联系方式

当 LocalConvert 的功能或隐私处理方式发生变化时，我们可能更新本政策。更新日期和生效日期标明当前版本。政策版本更新后，应用会在您使用工具前再次征求同意。旧版本中的“继续”操作不视为对本政策的同意。您随时可以在 Settings（设置）→ 隐私 → 阅读隐私政策中重新打开完整政策；英文和简体中文版均内置于应用中，可离线阅读。
